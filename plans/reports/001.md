## Deviations

1. **Preflight false-positive.** `scripts/preflight.sh` treats every backtick on the first `Requires` line as a filesystem path, so `verify:static` / `verify:web` / `verify:electron` were reported missing. Artefacts exist as npm scripts.
2. **Step 3 CSS grep counted 1.** Lightning CSS added `-webkit-backdrop-filter` to `transition-property`. The before line has no vendor-prefix substring, so the mechanical `grep -vcE -- '-(webkit\|moz\|ms\|o)-'` printed `1`. All other diffs were prefix-only.
3. **`applyTheme` eslint-disable.** Exporting `applyTheme` from `ThemeManager.tsx` trips `react-refresh/only-export-components`. Files list does not allow a new module. Added a one-line disable.
4. **`palette-classes.test.ts` comment.** Plan JSDoc `src/**/*.tsx` contains `*/` and broke esbuild. Comment now says `src TSX files`.
5. **Visual baselines (Step 6).** Light editor and confirm-dialog failed `maxDiffPixelRatio: 0.01` after the toolbar token swap (intended). Snapshots updated; those PNG paths were not on Step 6's Files list.
6. **Step 7 combined grep.** `grep -cE 'bg-black\|border-neutral-600'` is `1` because a token colour swatch still uses `border-neutral-600`. Toolbar no longer has those classes.
7. **Pause-button hover.** After click, Playwright leaves the pointer on the button so `.is-paused:hover` (`--app-error-solid-hover`) was compared to `--app-error-solid`. Added `page.mouse.move(0, 0)` after each click.
8. **Draft PR opened before Step 10 verify.** Cloud-agent rule. https://github.com/kocheck/Graphium/pull/263 is updated with this report after `npm run verify` exited 0.
